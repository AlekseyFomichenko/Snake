# 🐍 Классическая игра "Змейка" на C#

Консольная реализация классической игры "Змейка" с использованием ООП и системного ввода/вывода.

## 🎮 Особенности игры
- Управление змейкой стрелками (← ↑ → ↓)
- Определение столкновений с границами и телом

## 💻 Технологии
- **Console API** (цвета, позиционирование курсора)
- **ООП** (инкапсуляция, наследование)
